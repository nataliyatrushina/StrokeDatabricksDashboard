# Stroke Analytics Dashboard with Databricks

This project explores a public stroke dataset using Databricks SQL and AI/BI Dashboards.

The main goal was to become familiar with the Databricks analytics workflow by revisiting a dataset I had previously used for a university machine learning project. Since I already knew the data, I could focus on learning the platform, SQL-based data preparation, and interactive dashboard development.

## Features

- Data preparation using Databricks SQL
- Interactive dashboard built with Databricks AI/BI Dashboards
- Stroke prevalence by demographic and clinical risk factors
- BMI and glucose distributions by stroke status
- Age × hypertension heatmap

## Tools

- Databricks
- Databricks SQL
- Databricks AI/BI Dashboards

## Dataset

The project uses the public Stroke Prediction Dataset available on Kaggle:
https://www.kaggle.com/fedesoriano/stroke-prediction-dataset
